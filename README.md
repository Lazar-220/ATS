# ATS tool

A CV-ranking service: HR uploads a job posting PDF and CV PDFs, and the system scores every CV against
the posting's requirements and shows a ranked list with a verdict and a verbatim quote per requirement.

Prerequisites, first run, `make` commands and environment variables are in [docs/SETUP.md](docs/SETUP.md).
Architecture and scope are in [docs/plan.md](docs/plan.md); phase status is in [docs/PROGRESS.md](docs/PROGRESS.md).
