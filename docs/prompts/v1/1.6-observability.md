# Phase 1.6: Observability

**Read first:** §5.4, §6.1 (cost bullets), §6.3 (Langfuse row and the RAM budget) of `docs/plan.md`.
**Depends on:** 1.5.
**Branch:** `phase/1.6-observability`

## Goal

For every assessment the prompt, tokens, cost and latency are visible in Langfuse, and the cost
per CV and p95 per step are known numbers.

## Build (commit units)

1. **`feat(infra): add langfuse self-host compose file`**
   A separate compose file for Langfuse's six services, taken from the current official self-host
   instructions; do not write it from memory. `make langfuse-up` and `make langfuse-down`.
   Record `docker stats` for the six services.

2. **`feat(llm): trace every llm call`**
   In `LLMClient`: model, prompt version, input, output, tokens, latency, cache hit. Tracing is
   off unless `LANGFUSE_ENABLED` is true, and the application runs normally without Langfuse.

3. **`feat(pipeline): add one trace per assessment with a span per step`**
   Spans for extraction, masking, parsing, judge, quote check and score. Store the trace id on the assessment.

4. **`feat(llm): compute cost per call and per assessment`**
   Prices per million tokens in configuration (input, output, cached input). Thinking tokens are
   billed as output. Store the cost on the assessment.

5. **`feat(eval): send eval runs to langfuse as a dataset and an experiment`**
   So two runs can be compared per item.

6. **`docs: record cost per cv and p95 per step`**

## Out of scope

Alerting, dashboards beyond what Langfuse provides, hosted Langfuse.

## Done when

- [ ] Opening one assessment in Langfuse shows the prompt, tokens, cost and latency of each LLM call.
- [ ] Cost per CV and p50 and p95 per step are recorded in `docs/PROGRESS.md`.
- [ ] With `LANGFUSE_ENABLED=false` and Langfuse stopped, `make check`, the worker and the eval all run.
- [ ] Two eval runs appear in Langfuse as experiments on the same dataset.
- [ ] The measured memory of the Langfuse stack is recorded, with a note on what must be stopped while it runs.

## Traps

- Langfuse needs at least 4 GB of RAM (§6.3). Before `make langfuse-up`, check `docker stats` and tell me what to stop.
- Traces store prompts. They contain masked text only; verify that no span attribute carries the candidate's personal data.
- Check the current Langfuse Python SDK documentation for the tracing decorator and the dataset API before using them.
- Prices change (§6.1: the introductory price ends on December 31, 2026). Keep them in configuration, with the date they were checked.
